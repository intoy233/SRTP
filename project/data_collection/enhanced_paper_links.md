## 推荐搜索资源

### 免费学术资源
1. **Google Scholar**: https://scholar.google.com/
   - 最全面,有"所有版本"功能找免费PDF

2. **ResearchGate**: https://www.researchgate.net/
   - 可直接向作者请求全文
   - 注册免费

3. **Semantic Scholar**: https://www.semanticscholar.org/
   - AI驱动搜索,推荐相关论文

4. **arXiv**: https://arxiv.org/
   - 物理/工程预印本,完全免费

5. **J-STAGE**: https://www.jstage.jst.go.jp/
   - 日本学术文献,部分免费

### 付费数据库 (需机构访问)
1. **ScienceDirect**: Elsevier出版社 (Engineering Structures, J. Wind Engineering等)
2. **ASCE Library**: 美国土木工程师学会
3. **IEEE Xplore**: IEEE文献数据库
4. **Web of Science**: 综合学术数据库
5. **CNKI**: 中国知网 (中文文献)
6. **万方数据**: 中文学术数据库

### 搜索技巧
```
# 精确搜索
"exact phrase in quotes"

# 限定文件类型
filetype:pdf

# 限定网站
site:researchgate.net

# 排除关键词
-keyword

# 作者搜索
author:"Last Name"

# 组合搜索示例
"bridge VIV" "wind tunnel" filetype:pdf site:researchgate.net
```
