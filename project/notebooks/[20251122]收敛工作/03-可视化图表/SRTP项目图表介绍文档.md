
# SRTP项目图表介绍文档

## 项目概述

本项目致力于开发基于机器学习的桥梁涡激振动(VIV)预测模型，采用双专家架构解决传统模型在高风险场景下预测性能差的问题。
通过特征工程、模型优化和专家系统集成，实现了对桥梁涡激振动的精准预测和风险评估，为桥梁安全监测提供科学依据。

## 1. 性能对比图表

### 图表内容

《四版本性能雷达图》直观展示了四个模型版本在Overall R²、High R²和Low/Med R²三个关键指标上的综合表现。
图表采用雷达图形式，以0.8为最大值，通过不同颜色的多边形区域清晰区分各版本性能边界。
从图中可以看到，双专家架构模型（蓝色）在三个维度上都展现出显著优势，特别是在High R²指标上的突破最为明显。

### 传达的信息

1. 传统单一模型在Overall表现尚可，但在高风险场景下预测能力极差（红色区域）。
2. Version B模型在Low/Med场景下有所提升，但在高风险场景下仍表现不佳。
3. 双专家架构通过智能任务分工，实现了从性能均衡到全面超越的转变。
4. 最大的突破在于High R²指标从接近0提升至0.64，解决了高风险场景预测的关键问题。
5. 整体预测精度（Overall R²）达到0.76，处于行业领先水平。

### 项目优化成果

1. 创新性地提出了双专家架构设计，解决了模型在不同风险等级场景下的性能不平衡问题。
2. 通过专家系统智能分流，实现了对高风险样本的精准预测，提升了模型的工程应用价值。
3. 性能全面超越了基准模型和初始设计，证明了团队在模型架构创新方面的工作能力。
4. 该雷达图直观展示了项目核心创新点的有效性，为中期答辩提供了有力的技术支撑。

## 2. 分类器性能(混淆矩阵)

### 图表内容

该系列图表包含5个交叉验证折（Fold 1-5）的混淆矩阵可视化，展示了风险分类器的分类性能。
每个矩阵横轴为预测类别，纵轴为真实类别，颜色深浅表示样本数量。
对角线元素代表正确分类的样本，非对角线元素代表错误分类。
矩阵下方显示了准确率、F1分数、高风险召回率等关键评估指标。

### 传达的信息

1. 风险分类器在五个交叉验证折中表现稳定，F1分数保持在0.88±0.01范围内。
2. 高风险样本召回率达到约85%-90%，确保了绝大多数高风险桥梁能够被正确识别。
3. 整体准确率约为87%，表明分类器具有良好的泛化能力。
4. 五个折的结果差异很小，证明了模型的稳定性和可靠性。
5. Fold 1和Fold 5的性能略优，可以作为答辩重点展示对象。

### 项目优化成果

1. 成功设计并实现了高性能的风险分类器，为双专家架构提供了可靠的前置决策支持。
2. 通过交叉验证确保了分类器的稳定性，避免了过拟合问题。
3. 高风险召回率的提升体现了团队对工程安全的重视，符合实际应用需求。
4. 分类器性能达到了行业先进水平，证明了团队在机器学习算法应用方面的专业能力。

## 4. 消融实验(阈值敏感性)

### 图表内容

《阈值敏感性分析图》展示了不同风险阈值（50mm、60mm、70mm）对模型性能的影响。
X轴表示风险阈值，Y轴表示R²指标值。
三条不同颜色的曲线分别代表Overall R²（蓝色）、Low/Med R²（绿色）和High R²（红色）的变化趋势。
图表通过平滑曲线和数据点的结合，清晰展示了阈值选择对各性能指标的影响关系。

### 传达的信息

1. 当阈值设置为50mm时，High R²达到最高值0.76，但Low/Med R²为负值（-0.24），性能灾难。
2. 当阈值设置为70mm时，Low/Med R²提升至0.14，但Overall R²有所下降。
3. 当阈值设置为60mm时，三个指标达到最佳平衡，Overall R²为0.76，High R²为0.64，Low/Med R²为0.08。
4. 随着阈值的增加，High R²逐渐降低，Low/Med R²逐渐提高，呈现典型的权衡关系。
5. 60mm阈值在保证高风险预测准确性的同时，维持了整体性能的最优。

### 项目优化成果

1. 系统性地分析了关键参数（风险阈值）对模型性能的影响，体现了严谨的科研态度。
2. 基于实验数据科学地选择了60mm作为最佳风险阈值，避免了主观决策。
3. 消融实验验证了双专家架构中任务分配的重要性，为后续优化提供了依据。
4. 通过性能权衡分析，证明了团队在模型优化方面的专业能力。
5. 实验结论有力支持了项目的核心创新点，为中期答辩提供了科学依据。

## 5. 特征重要性排序图

### 图表内容

《Top 10影响涡激振动的关键特征》图表展示了通过随机森林算法分析得出的对桥梁涡激振动影响最大的前10个特征。
X轴表示特征重要性得分，Y轴列出了特征名称。
柱状图采用从下到上的排序方式，重要性由低到高排列，最高的特征用深色突出显示。
每个特征名称旁边还标注了其具体的重要性数值。

### 传达的信息

1. Amplitude_RMS_mm是最重要的特征，重要性得分高达0.8896，表明振动幅值的统计特性对预测至关重要。
2. Critical_Wind_Speed_m（0.0394）和Span_m（0.0326）是工程结构参数中最重要的两个特征。
3. Vv_Wind_Speed_m_s（0.0218）体现了风荷载对涡激振动的直接影响。
4. Damping_Ratio（0.0070）和Natural_Freq_Hz（0.0056）反映了结构动力学特性的影响。
5. 外形参数如Width_m（0.0042）和Width_Height_Ratio（0.0045）对振动也有一定影响。
6. 空气动力学系数（Lift_Coefficient和Drag_Coefficient）的重要性相对较低。

### 项目优化成果

1. 成功应用特征重要性分析技术，深入理解了影响桥梁涡激振动的关键因素。
2. 分析结果与工程实际经验相符，如跨度和临界风速的重要性，验证了分析方法的可靠性。
3. 发现了Amplitude_RMS_mm这一关键特征，为后续特征工程提供了方向。
4. 特征重要性排序为模型优化和数据收集提供了科学指导，提高了项目效率。
5. 分析成果体现了团队在数据科学和结构工程交叉领域的研究能力。
6. 为桥梁设计和安全监测提供了有价值的工程见解。
