## 🔑 关键技术方法

### 1. 文献检索策略

**检索式**:
```
(bridge OR cable-stayed OR suspension) AND
(vortex-induced vibration OR VIV OR vortex shedding) AND
(amplitude OR critical wind speed OR Scruton number)
```

**数据库**:
- Web of Science (SCI/EI)
- CNKI (中国知网)
- Google Scholar (补充)

**筛选标准**:
1. 包含真实桥梁案例 (非纯理论)
2. 提供振幅或临界风速数据
3. 发表年份: 2000年后 (数据可靠性)

---

### 2. 数据提取模板

**必填字段**:
- Bridge_Name (桥梁名称)
- Span_m (跨度, 米)
- Width_m (宽度, 米)
- Height_m (高度, 米)
- Amplitude (振幅, mm) ⭐ 标签
- Critical_Wind_Speed_ms (临界风速, m/s)

**选填字段**:
- Damping_Ratio (阻尼比)
- Natural_Freq_Hz (固有频率, Hz)
- Drag_Coefficient (阻力系数)
- Lift_Coefficient (升力系数)

**数据来源标注**:
- Paper_DOI (论文DOI)
- Data_Source (Real/Empirical) ⭐ 区分真实/经验数据

---

### 3. 链接收集策略 (创新点!)

**问题**: 许多论文只提到桥梁名称,缺少详细参数

**解决方案**:
```
1. 提取桥梁名称列表
2. Google Scholar搜索: "桥梁名称 + VIV"
3. 找到原始论文/设计报告
4. 补全缺失参数
```

**案例**:
```
论文A提到: "西侯门大桥发生涡激振动,振幅52mm"
但缺少: 跨度、阻尼比、临界风速

通过链接收集:
→ 搜索"西侯门大桥 VIV"
→ 找到陈政清团队的监测报告
→ 补全所有参数
```

**效果**:
- 补全率: 38% (28/73)
- 数据完整度: 78% → 92%

---

### 4. 数据质量检查

**物理一致性检查**:
```python
# 检查1: 振幅应在合理范围内
assert 5 <= Amplitude <= 300  # mm

# 检查2: 临界风速应在合理范围内
assert 3 <= Critical_Wind_Speed <= 20  # m/s

# 检查3: 宽高比应合理
assert 2 <= Width/Height <= 20

# 检查4: 能量关系
# Amplitude应与Scruton数反相关
correlation(Amplitude, Scruton) < 0
```

**异常值检测**:
```python
# 使用IQR方法检测异常值
Q1 = np.percentile(Amplitude, 25)
Q3 = np.percentile(Amplitude, 75)
IQR = Q3 - Q1
lower = Q1 - 1.5 * IQR
upper = Q3 + 1.5 * IQR

outliers = (Amplitude < lower) | (Amplitude > upper)
```

## 💡 经验教训

### 1. 数据收集的"二八定律"

**观察**:
- 80%的时间用于收集最后20%的数据
- 前45座桥梁用时1周,后31座桥梁用时3周

**启示**:
- 初期容易找到的数据很快,后期需要"链接收集"等技巧
- 设定合理的时间预期,避免过度乐观

---

### 2. 数据质量 > 数据数量

**案例**:
- 提取了82座桥梁,但去重+质检后剩76座
- 删除了6座重复样本和3座异常样本

**启示**:
- 宁缺毋滥,低质量数据会污染模型
- 数据清洗阶段必须严格

---

### 3. 组员协作的重要性

**成功经验**:
- 明确分工: A负责SCI, B负责学位论文, C负责CNKI, D负责清洗
- 定期同步: 每周组会,避免重复劳动
- 工具统一: 使用统一的数据提取模板(Excel)

**失败教训**:
- 初期未统一模板,导致数据格式混乱
- 部分组员理解错误,提取了错误参数
