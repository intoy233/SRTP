## 🏗️ 三、模型架构

### 3.1 Stacking架构图

```
输入: 桥梁参数 (17个原始特征)
    ↓
特征工程: Griffin Plot + 交互特征 + 幂函数变换
    ↓
特征空间: 78维

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【Level 0: 基学习器】(5个模型并行)

┌─────────────────────────────────┐
│  1. Ridge(alpha=10.0)           │ → 预测1
│     线性,L2正则化,稳定          │
├─────────────────────────────────┤
│  2. Lasso(alpha=0.1)            │ → 预测2
│     线性,L1正则化,稀疏特征      │
├─────────────────────────────────┤
│  3. RandomForest(n=100,d=10)    │ → 预测3
│     非线性,集成,鲁棒            │
├─────────────────────────────────┤
│  4. SVR(kernel=rbf,C=10)        │ → 预测4
│     核方法,局部拟合             │
├─────────────────────────────────┤
│  5. BayesianRidge               │ → 预测5
│     概率建模,不确定性           │
└─────────────────────────────────┘
    ↓ (5个预测值作为元特征)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【Level 1: 元学习器】

┌─────────────────────────────────┐
│  BayesianRidge                  │
│  智能融合5个预测                │
│  自动学习最优权重               │
│  输出: 预测值 + 不确定性        │
└─────────────────────────────────┘
    ↓
最终输出: 振幅预测 ± 不确定性
```

---

### 3.2 特征工程流程

```
原始特征 (17个)
    ↓
【物理特征计算】
├─ Scruton_Number = Damping × (Width/Height) × 100
├─ Reduced_Velocity = CriticalWindSpeed / (Freq × Width)
├─ Stiffness_Parameter = Freq × √Span
└─ VIV_Susceptibility = 1 / Damping

    ↓
【Griffin Plot特征】(VIV锁定区域)
├─ is_in_lock_in_region (Vr ∈ [4, 8])
├─ vr_lock_in_response (高斯响应)
├─ Scruton_in_lock_in (物理-锁定耦合)
└─ lock_in_depth (锁定深度)

    ↓
【交互特征】
├─ Damping × Span
├─ Freq × Width
├─ Scruton × ReducedVelocity
└─ 等...

    ↓
工程特征 (26个)

    ↓
【幂函数变换】
X_all = [X, X², X³]

    ↓
最终特征空间 (78维)
```

## 🔧 四、使用指南

### 4.1 快速开始

```python
# 安装依赖
pip install numpy pandas scikit-learn

# 导入模块
from final_viv_predictor import VIVPredictor

# 训练模型
predictor = VIVPredictor()
predictor.train('../data/final_bridge_dataset.csv', k=5)

# 保存模型
predictor.save_model('../models/stacking_viv_predictor.pkl')

# 预测新桥梁
bridge = {
    'Span_m': 1385,
    'Width_m': 35.9,
    'Height_m': 3.0,
    'Damping_Ratio': 0.0030,
    'Natural_Freq_Hz': 0.125,
    'Critical_Wind_Speed_ms': 12.0
}

amplitude, uncertainty = predictor.predict(bridge)
print(f"预测振幅: {amplitude:.2f} ± {uncertainty:.2f} mm")
```

### 4.2 风险评估准则

| 预测振幅 | 风险等级 | 工程建议 |
|----------|----------|----------|
| **> 50mm** 或 **上界 > 70mm** | 🔴 高风险 | **强制风洞实验/CFD验证** |
| **30-50mm** | 🟡 中风险 | 考虑减振措施(TMD/粘滞阻尼器) |
| **< 30mm** | 🟢 低风险 | 初步安全,结合工程经验判断 |

**⚠️ 重要提示**:
- 模型仅供**初步筛查**,不能替代实验验证
- 高振幅(>60mm)预测精度相对较低,必须保守估计
- 使用**95%置信区间上界**进行风险决策

## 📈 五、性能分析

### 5.1 成功原因

1. **特征工程有效**:
   - Griffin Plot物理特征捕捉VIV锁定区域
   - 幂函数变换引入适度非线性

2. **模型架构合理**:
   - 5个基学习器多样性强(线性+非线性+概率)
   - Stacking智能融合,降低方差

3. **防过拟合措施**:
   - 5-Fold交叉验证
   - 使用cross_val_predict生成元特征(避免数据泄露)
   - 基学习器参数保守(max_depth=10,避免过拟合)

4. **保留不确定性**:
   - 元学习器使用BayesianRidge
   - 提供置信区间,工程应用更安全

---

### 5.2 局限性

| 问题 | 原因 | 影响 | 应对措施 |
|------|------|------|----------|
| **高振幅预测弱** | 高风险样本不足(51/190) | >60mm误差较大 | 收集更多高振幅数据 |
| **置信区间偏宽** | 小样本不确定性高 | 平均±14mm | 扩充数据集至300+ |
| **国际桥梁泛化差** | 中国桥梁占85% | 可能偏向中国设计 | 补充国际案例 |
| **特征维度高** | 78维 vs 190样本 | 样本/特征比=2.4 | 特征选择降至50维 |
