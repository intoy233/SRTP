### 2. 路线C实验方案.md

**内容**: 路线C的实验设计文档

**实验设计**:
- 研究问题: 如何提升修正后的基线性能 (R²=0.59)
- 技术假设: 集成学习可以取长补短
- 实验方案: 路线A (深度学习) vs 路线B (物理混合) vs 路线C (集成学习)

**路线C核心思路**:
```
【Level 0: 5个基学习器】
├── Ridge (线性, L2正则)
├── Lasso (线性, L1正则, 稀疏)
├── RandomForest (非线性, 集成)
├── SVR (核方法, 局部拟合)
└── BayesianRidge (概率, 不确定性)
      ↓
【Level 1: 元学习器】
└── BayesianRidge (智能融合)
      ↓
  最终预测 ± 置信区间
```

**超参数设置**:
- Ridge: alpha=10
- Lasso: alpha=0.1
- RandomForest: n_estimators=100, max_depth=10
- SVR: kernel='rbf', C=1.0
- BayesianRidge: 默认参数

**用途**: 理解实验设计思路,复现实验

## 🔬 技术突破点

### 1. Stacking集成架构

**创新点**:
- 5个基学习器各有特长,取长补短
- 使用`cross_val_predict`生成元特征,防止数据泄露
- 元学习器使用BayesianRidge,保留不确定性

**为什么比单一模型好?**
```
Ridge: 线性,稳定,但拟合能力弱
RandomForest: 非线性,但容易过拟合
SVR: 局部拟合好,但全局性能差

Stacking: 融合三者优点,互补缺点
结果: R²从0.59提升至0.63 (+6.8%)
```

---

### 2. Griffin Plot特征 (虽然未提升性能,但有物理意义)

**理论基础**:
Griffin Plot描述了涡激振动的"锁定区域" (Lock-in Region):
- 当约化速度Vr在4-8之间时,振幅剧增
- 超出此区间,振幅衰减

**特征设计**:
```python
# 约化速度
Vr = U / (f × D)

# 锁定响应 (高斯曲线)
vr_lock_in_response = exp(-((Vr - 6) / 2)²)

# 是否在锁定区
is_in_lock_in = (Vr >= 4) & (Vr <= 8)

# 物理耦合
Scruton_in_lock_in = Scruton × is_in_lock_in
```

**结果**:
虽然R²未提升 (0.52 < 0.59),但这些特征有明确物理意义,可用于解释性分析。

---

### 3. 幂函数变换 (关键技术!)

**思路**:
VIV振幅与桥梁参数之间存在非线性关系,使用幂函数捕捉:

```python
# 原始特征: 26维
features = [Span, Width, Height, Damping, ...]

# 幂函数变换: 26 → 78维
X_linear = features
X_square = features²
X_cube = features³
X_all = [X_linear, X_square, X_cube]
```

**效果**:
- 单独使用: R²=0.59 (与基线持平)
- 结合Stacking: R²=0.63 (提升!)

**启示**:
幂函数变换本身未提升性能,但为Stacking提供了更丰富的特征空间。

## 📊 实验失败案例分析

### 失败案例1: 分诊-专家系统

**思路**:
根据风险等级分配专家模型:
- Low Risk (Amplitude ≤ 45mm) → Expert-L
- High Risk (Amplitude > 45mm) → Expert-H

**失败原因**:
- 高风险样本只有51座,不足以训练专家模型
- Expert-H性能极差 (R²=0.23)
- 整体性能: R²=0.44 (比基线更差!)

**教训**:
样本不足时,不要过度细分模型。这个教训在11月得到应用,采用了更合理的风险阈值 (60mm)。

---

### 失败案例2: XGBoost/LightGBM

**尝试**:
使用梯度提升树 (XGBoost, LightGBM)

**结果**:
- XGBoost: R²=0.54
- LightGBM: R²=0.54
- 都比基线(0.59)更差!

**失败原因**:
- 样本量不足 (190 < 500)
- 特征维度过高 (78维)
- Boosting容易过拟合

**教训**:
小样本场景,Stacking > Boosting

## 💡 经验教训

### 1. 集成学习的威力

Stacking将R²从0.59提升至0.63,虽然提升幅度只有6.8%,但这是在**真实数据、严格防泄露**前提下的提升,非常宝贵。

---

### 2. 物理特征的两面性

Griffin Plot特征虽然未提升性能,但:
- ✅ 有物理意义,便于解释
- ✅ 可用于特征重要性分析
- ❌ 不一定提升预测精度

**启示**: 物理特征和预测性能是两回事。

---

### 3. 失败也有价值

十月阶段尝试了:
- 路线A (深度学习, 失败)
- 路线B (物理混合, 失败)
- 分诊系统 (失败)
- Boosting (失败)

虽然都失败了,但这些失败为11月的双专家模型提供了**反面教材**:
- 不要用深度学习 (样本不足)
- 不要过度细分 (高风险样本不足)
- Boosting不适合小样本
