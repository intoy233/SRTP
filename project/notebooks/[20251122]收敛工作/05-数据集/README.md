## 📊 数据集概览

**基本信息**:

- 特征维度: 8个核心特征
- 标签: Amplitude (涡激振动振幅, mm)

### 阶段3: 数据清洗 (2024年11月中旬)

**清洗目标**: 删除物理冲突样本,补全缺失值

**清洗步骤**:

**Step 1: 删除异常样本 (9条)**

识别规则:
```python
# 异常振幅 (物理不合理)
Amplitude > 1000 mm or Amplitude < 1 mm

# 异常临界风速 (物理不合理)
Critical_Wind_Speed < 1 m/s or Critical_Wind_Speed > 50 m/s

# 异常宽高比 (断面形状不合理)
B/D > 100 or B/D < 1

# 重复样本 (完全相同的桥梁参数)
duplicated(subset=['B', 'D', 'L', 'Amplitude'])
```

**Step 2: 补全气动系数缺失值 (106条)**

补全策略:
```python
# Drag系数补全
if pd.isna(Drag):
    if B/D < 5:  # 流线型断面
        Drag = 0.7 ± 0.1
    elif 5 <= B/D < 10:  # 半流线型
        Drag = 1.2 ± 0.15
    else:  # 钝体断面
        Drag = 1.8 ± 0.2

# Lift系数补全
if pd.isna(Lift):
    # 基于断面形状和Strouhal数估算
    Lift = f(B/D, Strouhal) ± 0.1
```

**Step 3: 数据类型规范化**
```python
# 数值列转float64
float_cols = ['B', 'D', 'L', 'Amplitude', 'Critical_Wind_Speed', 'Drag', 'Lift']

# 类别列转category
category_cols = ['Source', 'Bridge_Type', 'Location']
```

**清洗效果**:
- 样本数: 475 → 466 (删除9条污染源)
- 真实Vcr占比: 56% → 58% (删除的主要是经验公式样本)
- 缺失值: 106条 → 0条
- 高风险样本: 198 → 205 (清洗后重新标注)

### 临界风速分布 (Vcr)

**真实测量值** (270条, 58%):
- 来源: 风洞实验/现场监测
- 范围: 3.2m/s - 16.8m/s
- 均值: 8.5m/s
- 标准差: 3.1m/s

**经验公式估算值** (196条, 42%):
- 公式: Vcr = St * f * D (Strouhal关系)
- 范围: 4.1m/s - 15.2m/s
- 均值: 9.1m/s
- 标准差: 2.8m/s

**真实值 vs 估算值对比**:
- 相关系数: 0.78
- 平均误差: 12.3%
- 结论: 经验公式在低/中风险段较准确,高风险段误差大

## 📝 数据使用建议

### 建模时的注意事项

**1. 特征缩放**
```python
from sklearn.preprocessing import StandardScaler

# 推荐: 标准化 (均值0,方差1)
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# 不推荐: MinMaxScaler (对异常值敏感)
```

**2. 训练/测试划分**
```python
from sklearn.model_selection import StratifiedKFold

# 推荐: 分层5折交叉验证 (保持风险等级分布)
skf = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)

# 分层依据: 风险等级 (Low/Medium/High)
risk_labels = (y > 60).astype(int)
for train_idx, test_idx in skf.split(X, risk_labels):
    ...
```

**3. 数据增强** (可选,高风险样本不足时)
```python
from imblearn.over_sampling import SMOTE

# 仅对高风险样本进行SMOTE过采样
smote = SMOTE(sampling_strategy={2: 300}, random_state=42)
X_resampled, y_resampled = smote.fit_resample(X, risk_labels)
```

### 特征工程建议

**推荐使用的派生特征**:
```python
# 1. 宽高比 (关键特征!)
features['B_D_ratio'] = df['B'] / df['D']

# 2. Strouhal数 (涡脱频率特征)
features['Strouhal'] = f * D / Vcr  # 需要知道涡脱频率f

# 3. 雷诺数 (流体特性)
features['Reynolds'] = Vcr * D / nu  # nu为空气运动粘度
```
