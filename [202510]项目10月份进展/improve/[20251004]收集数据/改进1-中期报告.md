#### 2.2.2 search_module.py - 学术搜索模块

**实现的搜索器**:
1. `GoogleScholarSearcher`: Google Scholar搜索(需手动辅助)

**核心功能**:
- 多关键词并行搜索
- 自动PDF下载
- 结果去重
- 错误处理和重试机制

**搜索关键词策略**:
```python
SEARCH_KEYWORDS = [
    "bridge vortex-induced vibration",

    "long-span bridge VIV",
    "桥梁涡振 风洞试验",
    "大跨度桥梁 涡激振动",
]
```

#### 2.2.3 parser_module.py - PDF解析模块

**解析能力**:
1. **文本提取**: 支持PyMuPDF和pdfplumber双引擎
2. **表格识别**: 自动识别和解析论文中的数据表
3. **正则匹配**: 智能提取跨度、频率、振幅等数值
4. **单位转换**: 自动识别并统一单位(m, mm, Hz, %)
5. **数据验证**: 合理性范围检查

**智能提取示例**:
```python
# 提取跨度
span_patterns = [
    r'(?:main span|主跨)[:\s]*([0-9.]+)\s*(?:m|米)',
    r'span[:\s]*([0-9.]+)\s*m'
]

# 提取振幅
amp_patterns = [
    r'(?:maximum amplitude|最大振幅)[:\s]*([0-9.]+)\s*(?:mm|毫米)',
]
```
