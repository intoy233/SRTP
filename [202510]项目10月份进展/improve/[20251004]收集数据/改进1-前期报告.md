## 1. 项目背景与目标

### 1.1 当前状态分析

我们的SRTP项目"基于数据和神经网络方法的大跨度桥梁涡振风险评估"目前面临一个核心矛盾:

**立项目标**: 构建深度学习神经网络模型进行桥梁VIV预测
**当前现状**: 仅有85座桥梁的小数据集,只能支撑岭回归等传统模型

### 1.2 当前数据集概况

- **数据规模**: 85座桥梁(含header共85行)
- **数据来源**: 主要为中国桥梁 + 少量国际著名桥梁
- **数据质量**: 真实数据,包含完整VIV实验参数
- **已有模型**: 物理VIV岭回归模型,R²=0.962

### 1.3 数据集字段分析

当前数据集包含26个字段:
```
BridgeID, BridgeName, BridgeType, Country, PaperSource, Year,
Span_m, Width_m, Height_m, Width_Height_Ratio, Total_Length_m,
Structure_Type, Natural_Freq_Hz, First_Freq_Hz, Second_Freq_Hz,
Drag_Coefficient, Lift_Coefficient, VIV_Wind_Speed_ms,
Critical_Wind_Speed_ms, Max_Amplitude_mm, Amplitude_RMS_mm,
Damping_Ratio, Vibration_Suppression, Suppression_Effect,
Risk_Level, Notes
```

**核心预测目标**: `Max_Amplitude_mm` (最大单振幅)

## 2. 数据收集需求分析

### 2.1 深度学习模型的数据量需求

根据深度学习经验法则:
- **最小数据集**: 500-1000样本(简单神经网络)
- **中等数据集**: 1000-5000样本(多层神经网络)
- **理想数据集**: 5000+样本(复杂深度模型)

**目标**: 至少扩充到**500-1000座桥梁**,理想达到**2000+座桥梁**

### 2.2 数据来源规划

#### 优先数据源:
1. **学术论文数据库**:
   - Google Scholar (谷歌学术)
   - Web of Science
   - Scopus
   - 中国知网(CNKI)
   - 万方数据库

2. **关键词策略**:
   - 英文: "bridge vortex-induced vibration", "long-span bridge VIV", "wind tunnel test"
   - 中文: "桥梁涡振", "风洞试验", "涡激振动"

3. **数据类型**:
   - 风洞试验数据(优先)
   - 现场监测数据
   - CFD数值模拟数据(补充)

### 2.3 数据字段对齐策略

需要提取的核心字段(必须与现有数据集兼容):

| 字段类别 | 必填字段 | 选填字段 |
|---------|---------|---------|
| **基本信息** | BridgeName, Country | Year, PaperSource |
| **几何参数** | Span_m, Width_m, Height_m | Width_Height_Ratio |
| **动力特性** | Natural_Freq_Hz, Damping_Ratio | First_Freq_Hz, Second_Freq_Hz |
| **VIV响应** | Max_Amplitude_mm (目标变量) | VIV_Wind_Speed_ms, Amplitude_RMS_mm |

## 3. 技术方案设计

### 3.1 模块化架构

```
data_collection/
├── search_module.py      # 学术数据库搜索模块
├── parser_module.py      # PDF论文解析模块
├── main.py              # 主控制脚本
├── config.py            # 配置文件(关键词、字段映射)
└── utils.py             # 工具函数(数据验证、格式转换)
```

### 3.2 技术栈选择

- **Python 3.8+**: 主开发语言
- **requests/Selenium**: 网页交互和下载
- **BeautifulSoup4**: HTML解析
- **scholarly**: Google Scholar API
- **PyMuPDF/pdfplumber**: PDF文本提取
- **pandas**: 数据处理
- **re (正则表达式)**: 数据提取

### 3.3 数据提取策略

#### 智能识别策略:
1. **表格识别**: 优先提取论文中的数据表
2. **正则匹配**: 从文本中提取数值(跨度、频率、振幅等)
3. **单位转换**: 自动识别并统一单位(m, mm, Hz, %)
4. **缺失值处理**: 用NaN标记缺失字段

#### 数据验证规则:
- `Span_m`: 50-3000m (合理跨度范围)
- `Width_m`: 10-60m (合理宽度范围)
- `Height_m`: 1-10m (合理梁高范围)
- `Natural_Freq_Hz`: 0.05-2.0Hz (合理频率范围)
- `Max_Amplitude_mm`: 0.1-200mm (合理振幅范围)

## 5. 风险与挑战

### 5.1 技术挑战
1. **数据库访问限制**: 部分学术数据库需要订阅权限
2. **PDF解析难度**: 论文格式不统一,表格识别困难
3. **数据标准化**: 不同论文使用不同单位和参数定义

### 5.2 应对策略
1. **多源策略**: 结合免费和开放数据源
2. **半自动化**: 关键数据点人工复核
3. **数据映射**: 建立完善的字段映射和单位转换规则

### 5.3 质量保证
- 优先提取有明确数据表的论文
- 交叉验证不同来源的同一桥梁数据
- 保留原始论文来源(PaperSource)便于追溯
