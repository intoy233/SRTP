## 1. 策略调整说明

### 1.1 原策略的问题

❌ **直接爬取数据存在的障碍**:
- Google Scholar: 严格的反爬虫机制
- ScienceDirect/IEEE: 需要付费订阅
- CNKI/万方: 需要机构账号
- PDF自动解析: 准确率不足50%

### 1.2 新策略的优势

✅ **收集论文链接的优势**:
- 无需绕过反爬虫机制
- 您可使用学校VPN访问付费数据库
- 可以选择性下载高价值论文
- 人工复核确保数据质量
- 支持多种获取途径(ResearchGate请求全文、联系作者等)

## 4. 下载工作流程

### 4.1 第一阶段: 批量搜索 (预计1小时)

```
任务: 搜索CRITICAL级6篇论文
工具: Google Scholar + ResearchGate

步骤:
1. 打开paper_download_checklist.csv
2. 复制第1篇的Search_Keywords

5. 如无免费版,记录DOI或去ResearchGate请求全文
6. 重复2-5步,搜索完6篇CRITICAL论文
```

### 4.2 第二阶段: 批量下载 (预计30分钟)

```
任务: 下载可获取的PDF
工具: 浏览器 + 学校VPN

步骤:
1. 连接学校VPN(如有)
2. 下载所有可直接获取的PDF
3. 保存到D:\Desktop\SRTPCode\project\papers\
4. 统一命名: 作者_年份_关键词.pdf
5. 在CSV中标记Status为"Downloaded"
```

### 4.3 第三阶段: 批量解析 (预计2-3小时)

```
任务: 从PDF提取桥梁数据
工具: parser_module.py

步骤:
1. 运行: python parser_module.py --batch papers/*.pdf
2. 人工复核提取的数据
3. 修正错误或补充缺失数据
4. 合并到expanded_bridge_dataset.csv
```

## 5. 搜索技巧速查

### 5.1 Google Scholar高级搜索

```bash
# 基础搜索
"exact title in quotes"

# 限定作者
author:"Last Name"

# 限定年份
after:2020 before:2023

# 组合搜索示例
"European Bridge VIV Database" author:Larsen after:2018
```

1. 注册免费账号(必需)
2. 搜索论文标题
3. 点击"Request full-text"按钮
4. 等待作者回复(通常1-7天)

### 7.3 批量解析脚本(待开发)

```python
import os
from parser_module import parse_pdf

papers_dir = 'papers/'
output_data = []

        output_data.append(data)

import pandas as pd
```
